Ask which mission the learner wants if they have not said: Week 0 (first call, first trace) or the warm-up (the job-watch agent). Project 1 and later are part of the full program; if they ask for one, read `./missions/2-project1.md`, tell them plainly that it ships with the program, and point to https://deployed.so/courses.

Week 0 uses `./missions/0-week0.md`. The warm-up uses the `warm-up-mission` skill and `./missions/1-warmup.md`. Check the current directory for an existing `PREDICTION.md` and any agent code (or `hello.txt`, a script and `runs.txt` for Week 0) to see whether the user is starting or resuming, say which, and continue from the right step of the brief.
